Téléchargez le fichier correspondant à votre système ci-dessous. Si FaRFa project est déjà installé, il se met à jour tout seul.

## Nouveautés
- **Demander un jeu** : un jeu manque ? « + Demander un jeu », à côté de la recherche. Choisissez la console dans la liste (ou « Autre » pour une console pas encore sur le serveur), ajoutez un lien ou un message. Si le jeu semble déjà dans la bibliothèque, le launcher vous le montre avant d'envoyer.
- **Suivi des demandes** dans Messages (l'enveloppe) : l'onglet « Mes demandes » montre si votre demande est reçue, acceptée, ajoutée ou refusée, avec la réponse.
- **Menu de la musique** : l'icône ♪ en haut ouvre un petit menu avec le titre en cours, « Changer de musique » et les volumes de la musique et des bruitages.
- **Votre avatar RomM** s'affiche à côté de votre pseudo.
- **En-tête plus clair** : votre pseudo et les actions à droite, les onglets à gauche, des boutons plus petits et des icônes (messages, musique, rafraîchir, plein écran, paramètres).
- **Versions de test** : dans Paramètres → À propos, « Recevoir les versions de test » vous donne les nouveautés plus tôt. Laissez la case décochée pour ne recevoir que les versions stables.
- **Messages** : les onglets sont dans un nouvel ordre, avec les nouvelles versions en premier.

## Corrections
- **Musique coupée toute seule sous Windows** : une sécurité prévue pour Linux coupait le son si le launcher avait été fermé juste après son ouverture. Le son revient tout seul. La musique démarre aussi plus doucement.
