Téléchargez le fichier correspondant à votre système ci-dessous. Si FaRFa project est déjà installé, il se met à jour tout seul.

## Nouveautés
- Onglet « Contrôles » : boutons de la manette affichés avec leurs vrais noms (Xbox, PlayStation, Nintendo) et option pour bloquer le menu pendant le test.
- Bouton plein écran aussi sur la page d'un jeu.

## Corrections
- Windows : la manette pilote maintenant le launcher.
- Linux : une manette branchée après l'ouverture du launcher est détectée.
- La manette répond de nouveau après avoir quitté un jeu.
- Linux : bruitages du launcher rétablis.
- Linux : les images des jeux ne s'échangent plus brièvement.
- Les réglages de touches n'apparaissent que pour les jeux qui les prennent en charge.
