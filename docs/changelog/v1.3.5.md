Téléchargez le fichier correspondant à votre système ci-dessous. Si FaRFa project est déjà installé, il se met à jour tout seul.

Cette version apporte au Steam Deck (NieRDeck, à mettre à jour depuis son panneau) une bonne partie de ce que le launcher sait faire. Sur PC, rien ne change.

## Nouveautés
- **Steam Deck : boîtes 3D** des jeux, comme dans le launcher. Elles tournent toutes seules, et le stick droit les fait tourner sur la page d'un jeu.
- **Steam Deck : favoris**, les mêmes que dans le launcher. X sur un jeu l'ajoute ou le retire, et une entrée « Favoris » les regroupe.
- **Steam Deck : filtres** Tous / Installés / Recomp / Émulation (L2 / R2) et **saut à une lettre** (← →) dans les listes de jeux.
- **Steam Deck : badges** des jeux, comme dans le launcher : Installé, Mise à jour disponible, Nouveau, Installation…
- **Steam Deck : nouveaux onglets.** Bibliothèque et Collections sont réunies dans un onglet « Steam ». Les musiques ont leur onglet « Musique ». « Récents » montre les 20 derniers jeux lancés, avec leur provenance (Steam, FarfaLauncher ou autre). L'onglet Boutique disparaît.

## Corrections
- Steam Deck : le temps de jeu, les nouveautés et le classement de la page d'un jeu s'affichent enfin.
