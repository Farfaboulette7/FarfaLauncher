Téléchargez le fichier correspondant à votre système ci-dessous. Si FaRFa project est déjà installé, il se met à jour tout seul.

Cette version corrige l'image délavée des jeux PC sur un écran HDR, et ajoute une section pour soutenir le projet.

## Nouveautés
- **Paramètres → Soutenir le projet** : tout en bas des paramètres, les façons de soutenir FaRFa project (liens, et QR code quand il y en a un).

## Corrections
- Steam Deck OLED et Linux avec un écran HDR : les jeux PC lancés avec Proton (NieR:Automata…) n'ont plus de voile gris très clair par-dessus l'image. Sous Windows, rien ne change.
