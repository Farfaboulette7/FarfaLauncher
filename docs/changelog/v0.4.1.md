## Nouveautés
- Nouvelle catégorie « Ordinateur » dans la bibliothèque, pour des jeux PC.
- Prise en charge de plusieurs formats d'installation : installateurs, dossiers prêts à lancer, archives.
- Certains jeux proposent un choix de mode au lancement.
- Sous Linux : lancement des jeux Windows avec Proton, dont la version peut être choisie.
- Écran « Lancement en cours » jusqu'à l'ouverture du jeu.
- Détection des sauvegardes améliorée.

## Corrections
- La progression d'un téléchargement reste affichée pendant la vérification des fichiers.
- Téléchargements plus rapides pour les jeux composés de nombreux fichiers.
- Divers correctifs d'installation.

## À tester sous Linux / SteamOS
1. Un jeu natif Linux : installation et lancement.
2. Un jeu Windows avec Proton : premier lancement (téléchargement de Proton), changement de version de Proton.
3. Un jeu avec installateur : installation complète puis lancement.
4. Un jeu avec choix du mode : chaque mode se lance.
5. Sauvegardes d'un jeu lancé avec Proton : trouvées et envoyées sur le serveur après la partie.
6. Écran de lancement : il disparaît quand le jeu s'ouvre.
