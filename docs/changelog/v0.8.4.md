Téléchargez le fichier correspondant à votre système ci-dessous. Si FaRFa project est déjà installé, il se met à jour tout seul.

## Nouveautés
- **Menu en jeu** : pendant une partie, maintenez **Select + Start** une seconde. Une colonne glisse sur la gauche de l'écran avec la durée de la partie, l'heure et le nom du jeu, puis « Reprendre » et « Quitter le jeu ». Le jeu est en pause tant qu'elle est ouverte. Ça marche avec tous les émulateurs et toutes les recomps.
- **Nouveautés de l'émulateur ou de la recomp** : l'onglet « Informations » d'un jeu montre les notes de la dernière version de ce qui le fait tourner.
- **Livret** : les gâchettes de la manette tournent les pages.

## Améliorations
- Page d'un jeu : le résumé passe dans l'onglet « Médias », avant les captures ; « Informations » ne garde que les informations techniques.
- L'onglet « Mods » est remplacé par un bouton « Ouvrir le dossier des mods », affiché quand le jeu en a un.
- Onglet « Contrôles » : un bouton « Tester » par joueur. Pendant le test, le menu est bloqué ; maintenez Start 2 secondes (ou Échap) pour terminer.
- Navigation à la manette : le cadre autour de l'élément choisi est plus épais, on ne le perd plus de vue.
