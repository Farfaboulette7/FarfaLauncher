Téléchargez le fichier correspondant à votre système ci-dessous. Si FaRFa project est déjà installé, il se met à jour tout seul.

## Nouveautés
- **FaRFa project sur Steam Deck** : avec le plugin Decky NieRDeck, un onglet **Catalogue** liste les jeux du serveur par console (les recomps en tête) et les installe comme le launcher, avec les mêmes réglages (français, configuration des émulateurs, réglages optimisés pour le Deck). Chaque jeu installé reçoit sa page dans la bibliothèque Steam, avec sa jaquette, et se lance depuis le mode Jeu.
- **Sauvegardes partagées entre le PC et le Deck** : au lancement sur le Deck, la sauvegarde la plus récente est reprise ; à la fermeture du jeu (même avec « Quitter le jeu » de Steam), elle repart sur le serveur. Le temps de jeu est compté aussi.

## Corrections
- Après une partie, la sauvegarde est envoyée avant le temps de jeu : elle part même si le serveur répond lentement.
