## Nouveautés
- **Nouvel onglet « Communauté »** sur la page de chaque jeu :
  - **Classement** des amis sur le jeu ;
  - **Avis** : notez le jeu (note, difficulté, terminé à…), laissez un commentaire et lisez ceux des autres, avec la note moyenne. Les avis sont aussi visibles sur RomM ;
  - **Signalements** : tous les problèmes signalés sur le jeu, et ce qui a été corrigé grâce à vous.
- **Recomp ou émulation, plus clair** : le panneau d'installation dit dans quel mode le jeu se lance (« Jeu en mode recomp : … », « Jeu en mode émulation : … »), une étiquette le rappelle à côté de la console, et le bouton suit votre choix : « Installer *nom* » pour un mode pas encore installé, « Changer pour *nom* » pour un mode déjà sur le disque.
- **« Ouvrir la recomp »** : les recomps qui ont leur propre launcher (réglages, mods…) s'ouvrent dessus d'un clic, à côté de « Jouer ».
- **Dossier des mods** : Informations › Installation donne le dossier où mettre ses mods, d'après la documentation de la recomp ou de l'émulateur, avec un lien pour l'ouvrir.
- **Nouveautés de la recomp ou de l'émulateur** : un lien dans Informations › Installation ouvre les notes de la dernière version dans une fenêtre, pour le mode choisi.
- **Livret** : rangé dans Médias (Captures / Livret), et « Ouvrir le livret » dans Informations l'affiche directement en plein écran.
- **Tous les boutons du haut sur la page d'un jeu** : téléchargements, amis, messages, musique, rafraîchir, plein écran et paramètres.
- **Menu musique** : « Couper la musique » et « Couper les bruitages ».
- **Manette** : B ramène de la liste des jeux d'une plateforme à toutes les plateformes.

## Corrections
- **Statistiques** : chez certains joueurs, le temps de jeu n'arrivait jamais dans les statistiques (une partie sur un jeu retiré de RomM bloquait tout l'envoi). Tout l'historique remonte maintenant.
- **Rafraîchir relit vraiment tout** : bibliothèque, consoles déjà ouvertes, page du jeu, amis, messages, temps de jeu et sauvegardes en attente.
- **Animations** : la flèche de Rafraîchir tourne et les menus Musique et Amis s'ouvrent en douceur même quand Windows réduit les animations.
- **Livret en plein écran** : tourner une page ne fait plus sauter tout le livret.
- **Ouverture du launcher** : l'animation se joue en entier (elle se coupait sous Linux), et rien ne réagit aux clics ni à la manette tant qu'elle n'est pas finie.
