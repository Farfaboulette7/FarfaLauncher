## Nouveautés
- **Succès RetroAchievements** : un onglet « Succès » sur la page de chaque jeu qui en a. Vous y voyez tous les succès du jeu, ceux que vous avez débloqués (avec la date, et le mode hardcore), votre progression, et celle des amis sur le même jeu.
  - Pour voir vos propres succès, liez votre compte RetroAchievements : **Paramètres → RetroAchievements → Lier mon compte**, puis indiquez votre pseudo dans votre profil RomM. Vos succès se mettent à jour toutes les heures.
- **Historique des sauvegardes pour les jeux d'émulateur et les jeux PC** : comme pour les recomps, « Historique des sauvegardes… » sur la page du jeu montre les versions précédentes (date, appareil, taille) et permet d'en restaurer une. La version remplacée reste dans l'historique : rien n'est perdu. L'historique commence avec cette version.
- **Onglet Contrôles refait** : les joueurs J1 à J4 (rejoindre en appuyant sur un bouton, glisser-déposer pour échanger), les manettes détectées, les boutons (qui servent aussi de test en direct), la réactivité des manettes, et un profil pour ce jeu, tout l'émulateur ou tous les jeux. Enregistrement automatique.
- **Clavier et souris dans Dolphin** : ils comptent comme un joueur, et les boutons se réassignent par joueur.
- **Fenêtre plus grande à l'ouverture** : les onglets d'un jeu tiennent sur une ligne. Sur un petit écran, la fenêtre s'adapte toute seule.

## Corrections
- Un émulateur fermé sans fenêtre (Eden resté ouvert en arrière-plan) termine bien la partie et arrête le temps de jeu.
- Fermer la fenêtre quitte vraiment le launcher : il ne reste plus ouvert en arrière-plan, ce qui bloquait le lancement suivant.
