## Nouveautés
- **Ajouter à Steam** : dans la fiche d'un jeu installé, le lien « Ajouter à Steam » crée un raccourci dans votre bibliothèque Steam, avec la jaquette et une capture du jeu. Lancé depuis Steam, le jeu démarre par FaRFa project ; le launcher se ferme ensuite tout seul, pour que Steam compte le bon temps de jeu. Il faut redémarrer Steam pour voir le jeu (Steam → Quitter, puis le rouvrir). Sur le Steam Deck, rien ne change : le Catalogue de NieRDeck s'en occupe déjà.
- Rappel de la 1.1.0-beta.1 : panneau **Amis**, **Apparaître hors ligne**, **Statistiques** et classements entre amis.
